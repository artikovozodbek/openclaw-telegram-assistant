# Active Browser-Oriented Skills

This directory contains legacy/project browser automation skill templates that
are still useful for services without a stronger direct API or MCP route.

Do not place Telegram or Google Workspace/Google browser duplicate skills here
as active skills. Those services are routed through the durable workspace skills
instead:

- Telegram: `../../skills/telegram` and `../../skills/telegram-send`
- Google Workspace: `../../skills/gws-*`

Obsolete duplicate browser skills are archived in `../skills-disabled/` so they
remain recoverable but are no longer discovered by OpenClaw as active skills.
